# Use the starter in Bolt

## 1. Open it

In Bolt, import a project from GitHub and paste this repository's address:
`https://github.com/yclas/marketplace-starter`.

## 2. Settings

Create a `.env` file in the project, or ask Bolt to, with:

```
VITE_YCLAS_URL=https://your-marketplace.com
VITE_YCLAS_SITE_KEY=your-site-api-key
VITE_SITE_NAME=Your marketplace
```

## 3. Let the preview reach your site

Bolt's preview runs on its own address. Copy it from the preview's address bar and add it in your Yclas panel under
**Integrations > Your own front end**. Do the same for your domain when you publish.

## 4. Keep building by prompt

Start with *"Read AGENTS.md and follow it for every change"*. If Bolt offers Bolt Cloud's database for listings or users, say no: they're already on your
Yclas site.
