# Use it with v0

v0 builds Next.js apps by default, and this starter is a Vite app. Two ways:

1. **Start from the prompt (simplest).** Paste the **starter prompt** from your Yclas panel (**Integrations > Your
   own front end**) into v0. It builds a Next.js front end that follows the same rules: listings, sign-in, posting
   and messages through your Yclas API, and payments on your Yclas site.
2. **Bring this code.** Import the repository into v0 from GitHub. If v0 converts it to Next.js, keep
   `src/lib/yclas.ts` as it is: it's plain TypeScript and works in Next.js too (move the `VITE_` variables to
   `NEXT_PUBLIC_`).

Either way, add v0's preview address and your Vercel domain in your Yclas panel under **Integrations > Your own front
end**. If you call the API from Next.js server code instead, CORS doesn't apply there.

Not yet tested end to end in v0. Tell us how it goes.
